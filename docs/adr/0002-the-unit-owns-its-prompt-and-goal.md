# The output unit owns its prompt and goal

Every channel unit (Reel, TikTok, Tweet, Post) carries a prompt and a goal on the shared abstract base. The prompt is what that piece must say; the goal is the outcome it chases, empty meaning the campaign's default applies. A campaign can ship several pieces aiming at different outcomes, so the goal cannot live only on the brief, and the creative input belongs to the piece, not to one constant prompt in the step catalogue.

Considered and rejected: keeping both on the campaign only (one video could not chase follows while its sibling chased saves), and putting them on `Reel` alone (every later channel would need the same two columns).
